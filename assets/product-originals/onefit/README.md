# Originales de las correcciones de naranja

- `eaa-naranja-20261018.png`: copia exacta del adjunto del usuario «Bote EAA+ Essential sabor naranja.png».
- `colageno-naranja-completo-20261018.png`: copia exacta de la toma completa de Optimus Collagen 240 g naranja. Estaba asociada por error al EAA naranja en Storage (`d242dd6b-989a-49a4-9b20-e852cddb5561/8b168ff0-7353-4080-900e-8f691b2a9017.png`). El usuario pidió usar esa toma completa como referencia para corregir el borde.

No se retocan las etiquetas ni se sobrescriben estos archivos. El manifiesto `scripts/manifests/onefit-naranja-correcciones-20261018.json` genera copias WebP con altura de envase 800 px y base y=900. Las PNG se conservan como fuentes fuera de `public`; la tienda descarga únicamente los WebP responsive.

El registro local sustituye la presentación en catálogo y detalle para las rutas actuales exactas. Los objetos y asociaciones originales de Supabase se mantienen intactos. `sourceOverride` documenta la procedencia real de cada reemplazo; su `sourceHash` corresponde al archivo de entrada y `catalogSourceHash` identifica los bytes de Storage anteriores.
